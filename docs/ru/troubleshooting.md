# Решение проблем

## npm не может скачать zcode-acp

Оба репозитория открыты. Проверьте доступ к GitHub, наличие Git в PATH и локальные правила замены URL. SSH-ошибка `Permission denied (publickey)` может указывать на локальную замену адреса; в манифесте указан открытый HTTPS-источник. Сохраняйте закреплённый коммит модуля; не подменяйте его посторонним пакетом с таким же названием.

## В BB нет ZCode CLI

Убедитесь, что BB запущен, и выполните регистрацию:

```sh
node scripts/register-cli-agent.mjs --register
```

Откройте новый чат и ищите **ZCode CLI**, а не просто **ZCode**. Если скрипт не находит BB, укажите в `BB_CLI` официальный JavaScript entry point CLI BB или исполняемый файл и повторите. После переноса папки или установки Node зарегистрируйте агент заново.

## Node завершается с “bad option: --bb-permission=full”

Старая регистрация помещала аргументы адаптера перед скриптом Node. Текущая использует `insertAfterArgs: 1`: `node <script> --bb-permission=full`. Повторите команду регистрации.

## Не найден встроенный CLI

Установите ZCode Desktop на машине, где работает агент. Для нестандартного расположения задайте в окружении агента `ZCODE_NATIVE_ENTRY` с путём к `resources/glm/zcode.cjs`. Полная установка Desktop должна оставаться доступной.

## Нет нужного плана или модели

Переподключите правильный аккаунт в Desktop и запустите doctor. Start Plan отображается только при подтверждённом положительном балансе для известной модели каталога. Просроченные, будущие и исчерпанные выдачи исключаются. API-источники должны быть заранее настроены в ZCode. Наборы источников и моделей могут различаться между аккаунтами.

## Ошибка квот или устаревшие значения

Выберите правильную машину и отдельный источник ZCode в **Provider usage**, затем обновите. Общая ошибка панели может относиться к другому провайдеру. Просроченную авторизацию переподключите в Desktop. Старые значения сохраняют прежнее время наблюдения и не являются свежим балансом.

## Windows не может защитить папку сессии

Runtime использует `powershell.exe` и ACL Windows. Проверьте доступность Windows PowerShell 5.1 и его встроенного модуля безопасности. Родительский PowerShell 7 может передать несовместимый `PSModulePath`; попробуйте запуск из Windows PowerShell 5.1. В CI проверки ACP выполняются в этой оболочке. Не обходите защиту папки и не открывайте всем доступ к данным сессий.

## QR снова требует вход

Используйте тот же обычный профиль браузера и сохраняйте cookies. Получите актуальную полную ссылку Mobile Remote Control из Desktop. Входите через того же провайдера аккаунта. Для самостоятельных чатов BB локальный CLI использует вход Desktop без браузерного сопряжения.

## Сохранённая сессия не загружается

Возобновляются только собственные сессии адаптера `bb-native-*`, привязанные к тому же рабочему пространству. Если после отправленного ввода native history отсутствует, адаптер выдаёт ошибку и не отправляет сомнительный запрос повторно. Сохраните исходные данные сессии и папку; не переименовывайте задачу Desktop для принудительного совпадения.

## Как сообщить об ошибке

Укажите ОС, версии Node/BB/ZCode, команду и очищенную ошибку. Не прикладывайте токены, QR-ссылки, файлы аккаунта, базы сессий и личную переписку. Ошибки можно сообщать в [репозитории плагина](https://github.com/ichinya/bb-plugin-zcode/issues).
