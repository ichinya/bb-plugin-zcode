# ZCode для BB

Используйте доступные в аккаунте ZCode модели из BB. Плагин регистрирует **ZCode CLI**, разделяет источники моделей и добавляет квоты Coding Plan / Start Plan в стандартную панель использования BB.

[Установить плагин →](./installation.md)

## Один плагин и отдельный модуль

| Компонент | Назначение |
| --- | --- |
| [`bb-plugin-zcode`](https://github.com/ichinya/bb-plugin-zcode) | Интеграция с BB, регистрация, интерфейс и отображение квот. Пакет: `bb-plugin-zcode-acp`; ID установленного плагина: `zcode-acp`. |
| [`zcode-acp`](https://github.com/ichinya/zcode-acp) | Самостоятельный Rust-бинарник: ACP, авторизация Desktop, сессии, модели и квоты. Установка и обновление в настройках плагина либо выбор из PATH или по своему пути. |
| **ZCode CLI** (`acp-zcode-cli`) | ACP-провайдер для выбора в новом чате BB. |

Runtime — отдельный исполняемый файл, не второй плагин BB и не npm-зависимость. Адаптер автоматически использует Electron/Node runtime ZCode; для распознанной установки отдельный Node.js не требуется.

## Планы разделены

Источник указан в каждой строке выбора модели: **Coding Plan · Z.ai**, **Start Plan · Z.ai** или название личного API-подключения. Одинаковые названия моделей из разных источников сохраняют разные ID и маршруты.

## Возможности

- Текстовые запросы, потоковые ответы, события инструментов и запросы разрешений через ACP.
- Создание, загрузка и закрытие сессий; отмена текущего запроса.
- Выбор модели, режима и reasoning из каталога ZCode.
- Получение квот Coding Plan и Start Plan без запросов к модели.
- Открытие официального клиента удалённого управления по QR.

## Проверки и ограничения

Rust-сборка и тесты с фикстурами локально проверены в Windows. Сборки других ОС настроены в CI; удалённые результаты этой переработки пока не подтверждены. Поиск установленного ZCode реализован для Windows и macOS; Linux CI проверяет плагин и синтетический runtime. На Windows проверены аккаунт, каталог, выбор источников и квоты с Desktop 3.17.2, встроенным CLI 0.17.1 и BB 0.49.0. Реальная генерация и работа нативного адаптера на macOS здесь не квалифицированы.

Пока не поддерживаются изображения и аудио, Team Plan, интерактивные вопросы native runtime, управление браузером, собственные профили субагентов, fork/rewind и ручное сжатие контекста.
