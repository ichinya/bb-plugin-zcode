# Удалённое управление по QR

Для новых сессий BB используйте CLI/ACP. Для работы, уже открытой в ZCode Desktop, предназначена официальная ссылка **Mobile Remote Control**.

| Локальный CLI / ACP | Ссылка QR |
| --- | --- |
| Создаёт собственные нативные сессии адаптера. | Подключает официальный веб-клиент к существующему окну Desktop. |
| Использует сохранённую авторизацию Desktop. | Использует официальный вход в браузере и сопряжение. Постоянный профиль браузера может сохранить сессию. |
| Доступен в BB как **ZCode CLI**. | Плагин открывает веб-интерфейс; удалённый ACP не реализован. |

## Открытие официального клиента

1. В ZCode Desktop откройте **Mobile Remote Control**.
2. Скопируйте текущую ссылку в UTF-8-файл вне репозитория, например `../remote-link.txt` относительно папки плагина.
3. Из папки плагина проверьте ссылку:

   ```sh
   node bin/zcode-connect.mjs remote --link-file ../remote-link.txt
   ```

4. Откройте её в браузере по умолчанию:

   ```sh
   node bin/zcode-connect.mjs remote --link-file ../remote-link.txt --open
   ```

5. Войдите через тот же аккаунт и провайдера, что в Desktop, и завершите официальное сопряжение.

Принимаются только официальные ссылки `https://zcode.z.ai/remote/v4` с параметрами `sid`, `mid` и `app_version`. Сохраняйте URL полностью, включая версию. Не публикуйте ссылку и не включайте её в скриншоты: она содержит идентификаторы сопряжения.

## Как реже входить заново

Используйте один обычный профиль браузера и сохраняйте данные сайта. Приватное окно или очистка cookies могут потребовать повторного входа. Локальный ACP вообще не требует браузерного сопряжения, пока авторизация Desktop действительна.

С Desktop 3.17.2 наблюдались сопряжение, синхронизация рабочих пространств и открытие существующей неактивной задачи. Отправка, остановка и подтверждение реальных удалённых задач здесь не проверялись. Launcher не подтверждает успешное сопряжение и не реализует headless relay.

Официальное описание: [удалённое управление ZCode](https://zcode.z.ai/en/docs/remote-control).
