# Квоты планов

Откройте **Provider usage** внизу боковой панели BB. Выберите машину, на которой установлен ZCode, затем **All** или отдельный источник ZCode.

## Как читать строки

| Строка | Значение |
| --- | --- |
| **ZCode Coding Plan** | Окна квот, возвращённые сервисом аккаунта: пятичасовое, недельное или MCP/tools — если они присутствуют. Процент показывает расход, время — сброс по данным сервиса. |
| **ZCode Start Plan** | Доступные / всего токенов модели, процент расхода и срок действия выдачи. Истечение срока не обещает автоматическое продление. |

Отображаются только реально возвращённые окна. Отсутствующая недельная квота не вычисляется из другого лимита.

## Обновление и устаревшие данные

Список источников читается из локальных метаданных. Загрузка одного источника обращается только к его плану. Обычное чтение может использовать кэш до 60 секунд; **Reload provider usage** запрашивает свежий результат. Смена сохранённого аккаунта Desktop сбрасывает кэш.

При ошибке обновления может оставаться последний успешный результат с прежним временем наблюдения. Устаревшая строка не подтверждает текущий баланс. Если в общей панели ошибка другого провайдера, проверьте отдельную вкладку ZCode, чтобы отличить её от ошибки квот ZCode.

## Авторизация

Учётные данные остаются на выбранной машине и берутся из ZCode Desktop. Сбор квот не запускает ACP-запрос или модель, не получает промо-бонусы, не меняет план и не обновляет вход Desktop. Просроченную авторизацию переподключайте в Desktop.

Отдельный прежний плагин `zcode-usage` больше не нужен. Перед удалением старой установки убедитесь, что обе новые строки работают.
