# ZCode ACP

One BB plugin for **ZCode CLI / ACP**, separate **Coding Plan / Start Plan** model sources and plan quotas. Runtime: [Rust zcode-acp](https://github.com/ichinya/zcode-acp).

- **English:** [Documentation](https://ichinya.github.io/bb-plugin-zcode/en/) · [Markdown](docs/en/index.md)
- **Русский:** [Документация](https://ichinya.github.io/bb-plugin-zcode/ru/) · [Markdown](docs/ru/index.md)

Requires BB 0.49+ and signed-in ZCode Desktop. Install/update Rust ACP from the plugin settings, or use PATH/a custom executable path. Plugin ID: `zcode-acp`.
Нужны BB 0.49+ и вход в ZCode Desktop. Rust ACP устанавливается и обновляется в настройках плагина; также доступны PATH и свой путь к бинарнику. ID плагина: `zcode-acp`.
