# ZCode for BB

One BB plugin for **ZCode CLI / ACP**, separate **Coding Plan / Start Plan**
model sources and plan quotas. Runtime: [zcode-acp](https://github.com/ichinya/zcode-acp).

- **English:** [Documentation](https://ichinya.github.io/bb-plugin-zcode/en/) · [Markdown](docs/en/index.md)
- **Русский:** [Документация](https://ichinya.github.io/bb-plugin-zcode/ru/) · [Markdown](docs/ru/index.md)

Requires BB 0.49+, Node.js 24+ and signed-in ZCode Desktop.
Нужны BB 0.49+, Node.js 24+ и вход в ZCode Desktop.

Apache-2.0 · Based on / На основе [VKirill/bb-plugin-zcode](https://github.com/VKirill/bb-plugin-zcode).
